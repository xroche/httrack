# Races ThreadSanitizer reports that are deliberate, so the leg stays green and
# a new report means a new bug. Delete an entry once its reader stops racing.
#
# Every entry names a READER, never the writer. Suppressing the FTP worker
# instead would also hide its release store to lien_back.status going missing,
# and that is the regression this leg exists to catch.
#
# Every read of lien_back.status is an acquire load, and every access to a
# live FTP slot's r.size is a relaxed atomic, so neither needs an entry here.
#
# race_top, not race: race matches either stack at ANY frame, so it would hide
# a race on any field anywhere in the function or its callees. race_top matches
# the top frame only, which is the tightest the tool offers: TSan has no field
# or location suppression, and ANNOTATE_BENIGN_RACE_SIZED is reader-blind.
